# Stan Lane

This directory is the probabilistic comparison lane for the Darwin Research OS rewrite.

Scope:

- calibration baselines
- uncertainty estimation baselines
- posterior checks attached to benchmark, campaign, and program artifacts

Non-goals:

- Stan does not own the API
- Stan does not own orchestration
- Stan does not replace Sounio as the scientific kernel
- Stan does not replace F# as the rewrite target for the control plane
